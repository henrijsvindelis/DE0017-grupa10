Servera puse:

Satvars: Express.js — efektīvs risinājums JavaScript bāzētām tīmekļa lietotnēm;

Programmēšanas valoda: JavaScript — loģikas un servera puses koda izstrādei;

Datu bāze: MongoDB — dokumentu bāze, kas ir ērta recepšu, sastāvdaļu un lietotāja pielāgoto ēdienreižu plānu glabāšanai;

Tīmekļa serveris: Nginx — darbojas kā starpniekserveris un pārsūta pieprasījumus uz Express lietotni

Operētājsistēma: Ubuntu Linux - populāra un stabila servera operētājsistēma;

Virtualizācija: Docker, piem., AWS

Klienta puse:

Struktūra un stils: Tailwind CSS - ērtai un vizuāli pievilcīgai formu un kaloriju kalkulatora izveidei;

Programmēšanas valoda: JavaScript;

Lietotāja saskarnes bibliotēka, ietvars vai natīvā lietotne: React.js — nodrošina ātru lietotāja saskarni, kurā lietotājs var ērti ievadīt datus un uzreiz redzēt ģenerēto ēdienkarti bez lapas pārlādēšanas
